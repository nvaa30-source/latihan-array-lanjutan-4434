Deskripsi
Repository ini berisi latihan dasar penggunaan Array dalam JavaScript, meliputi pembuatan Array, mengakses dan mengubah elemen, serta penggunaan properti length.

Daftar Latihan
Soal 1 — Membuat Array
Soal 2 — Mengakses Elemen Array
Soal 3 — Mengubah Elemen Array
Soal 4 — Menggunakan Properti length
Soal 5 — Studi Kasus Data Siswa
Cara Menjalankan Program
Buka folder proyek menggunakan Visual Studio Code.
Buka Terminal.
Jalankan file JavaScript menggunakan Node.js.
Contoh:

node soal-1.js
Ganti nama file sesuai soal yang ingin dijalankan.
